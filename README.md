# Fiorito_et_al_2026
This repository contains bioinformatic analyses and figure-generation scripts for Fiorito et al. 2026 


## Repository structure

- `scripts/`: scripts used for the bioinformatic analyses described in the Methods and to generate the main and extended data/supplementary information figures
  
  - `analyses/`: scripts for bioinformatic analyses
    
  - `figures/`: scripts for generating figures

Detailed information about each workflow is provided in the README file within each directory.
