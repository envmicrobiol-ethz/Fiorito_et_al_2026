## Scripts


- `01_identify_putative_MHCs.py`: scans predicted proteins from MAGs, reference genomes or metagenomic assemblies for CXXCH, CXXCX₀–₇₀H and CX₁–₇₀CH motifs and retains proteins containing at least three motifs of the same type as candidate multiheme cytochromes. This script was used for screening peat metagenomes and electroactive reference microbes mention in the study.
