

01_predict_signal_peptides_cluster_representatives.sh: predicts signal peptides with SignalP v.60 for the conserved MHC cluster representatives selected for structural analysis.

02_search_MHC_structures_against_PDB100_foldseek.sh: searches the selected best structural models of peat-metagenome MHC cluster representatives against the PDB100 database using Foldseek v8-ef4e960.

03_compare_electroactive_context_models_to_EET_models_foldseek.sh: compares the selected best AlphaFold3 models from five electroactive reference-microorganism genomic contexts against the selected peatland EET structural models using Foldseek.
