# 10 — EET-bearing MAGs

These scripts build the sample-resolved comparison between EET machinery
expression and alternative respiratory pathways in EET-bearing MAGs.

Run the scripts in numerical order.

## 1. Alternative pathway expression

```text
01_build_sample_resolved_alternative_pathways.py
```

Main outputs used downstream:

```text
EET_MAG_membership.tsv
selected_markers_expression_by_MAG_sample.tsv
selected_modules_expression_by_MAG_sample.tsv
```

## 2. EET machinery expression

```text
02_build_EET_expression_by_MAG_sample.py
```

Main output used downstream:

```text
EET_machinery_expression_by_MAG_sample.tsv
```

## 3. EET-versus-alternative respiration tables

```text
03_prepare_EET_vs_alternative_respiration.py
```

This script reads the two main module-level tables generated by scripts 1
and 2 from the same analysis output directory.

## 4. Per-MAG correlations

```text
04_test_EET_alternative_respiration_correlations.py
```

Main output used for Supplementary Figure 2:

```text
refined_per_MAG_pathway_correlations.tsv
```

Sample and MAG names are used exactly as supplied in the input tables.
No aliases or depth-name corrections are applied. No fixed number of MAGs
is encoded in the scripts.
