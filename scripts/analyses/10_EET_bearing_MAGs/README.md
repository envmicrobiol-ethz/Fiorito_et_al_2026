# 10 — EET-bearing MAGs

These scripts build the sample-resolved comparison between EET machinery
expression and alternative respiratory pathways in EET-bearing MAGs.

Run the scripts in numerical order:

1. `01_build_sample_resolved_alternative_pathways.py`  
   Extracts selected alternative-respiration markers and hydrogenases from
   MAG-level KEGG, PFAM and METABOLIC HMM expression profiles.

2. `02_build_EET_expression_by_MAG_sample.py`  
   Maps curated EET proteins to MAGs and summarizes EET expression by MAG,
   EET component and metatranscriptomic sample.

3. `03_prepare_EET_vs_alternative_respiration.py`  
   Combines EET machinery expression with alternative-respiration module
   expression and generates complete MAG-by-sample comparison tables.

4. `04_test_EET_alternative_respiration_correlations.py`  
   Defines refined pathways and calculates per-MAG Spearman correlations
   between EET expression and alternative pathway expression.

The correlation table generated by script 4 is used to produce
Supplementary Figure 2.

No fixed number of MAGs is encoded in these scripts. Analysis-set sizes and
EET-group totals are derived from the input tables.

Sample and MAG names are used exactly as supplied in the input tables. The scripts do not apply aliases or depth-name corrections.
