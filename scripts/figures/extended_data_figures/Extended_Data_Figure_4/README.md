## Scripts ED Figure 4

- `ED_Figure_4A.R`: plots metagenomic abundance of methane-cycling MAGs, using genus assignments and family-level labels for MAGs without an assigned genus.
- `ED_Figure_4B.R`: plots normalized metatranscriptomic expression of methane-cycling MAGs, using genus assignments and family-level labels for MAGs without an assigned genus.
- `ED_Figure_4C.R`: generates the methanogen metabolic-expression heatmap from MAG-level KEGG MT_coverage_per_cell profiles for selected methanogenic genera.
