# Figure 1

Scripts used to generate the individual panels of Figure 1.

- `Figure1A_gases_and_terminal_electron_acceptors.R`: generates the gas and terminal-electron-acceptor profiles for Björsmossen and Norra Romyren.
- `Figure1B_16S_spatial_composition.R`: generates the 16S rRNA taxonomic composition plot for the spatial profiles.
- `Figure1C_dbRDA_BM_NR.R`: generates the dbRDA of the Björsmossen and Norra Romyren microbial communities using the complete environmental dataset.
- `Figure1D_16S_deep_composition.R`: generates the 16S rRNA taxonomic composition plot for the deep peat profiles.
