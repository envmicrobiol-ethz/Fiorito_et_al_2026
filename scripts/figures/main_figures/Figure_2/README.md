## Scripts

- `a_Figure_2_contig_level.R`: generates the contig-level metatranscriptomic functional heatmap from KEGG and METABOLIC MT_coverage_per_cell profiles.

- `b_Figure_2_MAG_level.R`: generates the dominant-phylum bubble panel from MAG-level KEGG and METABOLIC MT_coverage_per_cell profiles and MAG taxonomy.
